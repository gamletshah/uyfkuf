Умный список задач
Простое веб-приложение для управления задачами с поддержкой PWA (Progressive Web App) и уведомлениями.

Особенности
Добавление, просмотр и управление задачами

Фильтрация задач: все, активные, выполненные

Уведомления о добавлении задач и напоминания о невыполненных задачах

Работает оффлайн благодаря Service Worker

Установка на устройство как PWA

Сохранение задач в локальном хранилище браузера

Технологии
HTML5

CSS3

JavaScript

Web Notifications API

Service Worker

Web App Manifest

Установка и запуск
Клонируйте репозиторий или скачайте файлы

Откройте файл index.html в браузере

Для установки PWA:

В Chrome: нажмите "Установить" в меню браузера

В других браузерах могут быть другие варианты установки

Использование
Введите задачу в поле ввода и нажмите "Добавить задачу"

Отмечайте задачи как выполненные с помощью чекбоксов

Используйте кнопки фильтрации для просмотра разных категорий задач

Нажмите "Включить уведомления" для разрешения показа уведомлений

Структура файлов
index.html - главная страница приложения

app.js - основной JavaScript-код приложения

style.css - стили приложения

manifest.json - конфигурация PWA

service-worker.js - скрипт Service Worker для оффлайн-работы

icons/ - папка с иконками приложения

Лицензия
Этот проект является открытым и бесплатным для использования.
